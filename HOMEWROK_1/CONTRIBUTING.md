Contributing Guide

Thanks for your interest in contributing.

Roles in This Project

Maintainer: reviews issues/PRs, manages releases, and keeps project direction.
Contributor: proposes fixes/features via issues and pull requests.
User: reports bugs, suggests improvements, and shares usage feedback.

Typical Contribution Workflow

1. Open an issue to discuss the bug or feature.
2. Fork the repository and create a topic branch.
3. Make small, focused commits with clear messages.
4. Add or update documentation/tests where needed.
5. Open a pull request and reference the related issue.

Good Practices

- Follow existing Bash style and keep scripts readable.
- Test behavior for argument input, pipeline input, and combined input.
- Keep README examples accurate.
- Avoid adding new runtime dependencies unless necessary.
